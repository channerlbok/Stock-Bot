## FrontEnd project for StockPile app

### install

    you should already be in the ./frontend foled to read this.  If not, navigate there in your terminal right now
    run ```npm install``` to ensure that all modules are installed

### run

    you should already be in the ./frontend foled to read this.  If not, navigate there in your terminal right now
    run ```npm start```
    * there is a possibility that you might be asked to configure defaults when running the project for the first time.  Enter 'y' if asked.
    this should spin up the frontend server on http://localhost:3000/ and automatically open your default browser to that page
